# Path placeholders in this bundle

Absolute paths from the development machine were replaced so this bundle works anywhere:

| Placeholder | Meaning |
|---|---|
| `$HOME` | the installing user's home directory |
| `$VAULT` | the operator's private notes vault; referenced as background reading only, the bundle does not need it |
| `$WORKSPACE` | wherever this bundle was extracted |
| `$REVIEW_DIR` | the operator's review folder for generated media; any folder works |
