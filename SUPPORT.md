# Support

Two routes, both answered by the same person. Pick whichever is easier for you — nobody is turned
away for choosing the "wrong" one.

## Email — for anything that is not a reproducible bug

**samora@itikia.co.ke** — <mailto:samora@itikia.co.ke>

Use it for: licence and invoice questions, procurement or vendor forms, a refund, "is this the right
tool for what we do", or a bug you cannot describe in a form. **You do not need to be a developer to
write here**, and you do not need to know the terminology — say what you are trying to get done.

- Answered within **one business day**.
- If you would rather talk than type, say so and leave a number; a call is fine.
- Every message reaches a human. There is no ticket bot in front of it.

Already paid and no licence email? Write to **hello@itikia.co.ke** (same inbox) with your order
reference (`dsh_…`) and the entity the licence should name. It is reissued the same day.

## GitHub issues — for a reproducible bug or a feature request

<https://github.com/samorachumbi/dsh-media-reader/issues/new/choose>

Use it when the report is genuinely public-safe and reproducible: a tool call fails the same way
twice, a file type misbehaves, a documented behaviour does not happen. Issues are public and
permanent, which is why they suit bugs and not billing.

Please **do not** open an issue for anything containing a credential, a customer's data, a private
file, or a security problem — email instead. See [SECURITY.md](SECURITY.md).

## Buying, and what the licence costs

<https://store.itikia.co.ke> — $79 / KSh 10,000 per team, one time, including 12 months of updates.
Pay by card (Paddle) or M-Pesa (Paystack). Buying needs no account and no call.

## What is not offered

There is no paid support tier and no SLA beyond the one-business-day reply above, and the plugin is
not a hosted service: it runs on your machine, so nobody on this side can see your files or your
session. If that is a problem for a deployment you have in mind, say so in an email and it will be
answered honestly.
